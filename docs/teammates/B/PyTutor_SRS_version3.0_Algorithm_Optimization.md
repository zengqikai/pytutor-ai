# PyTutor SRS 3.0 — Algorithm Optimization Update

本文档基于旧版 `SRS_version2.0.docx` 更新，保留 PyTutor 2.0 的新手引导、误区感知、渐进式提示和学习画像要求，并新增下一阶段算法优化 SRS：A（NLP/RAG）、B（数据结构/AST）、C（大数据/推荐系统）。

## 核心更新

- A：NLP 类，由我负责，重点优化 RAG 检索，包括重排序、混合检索权重、语义切分、Token 窗口、HNSW 参数和上下文压缩。
- B：数据结构类，由连哥负责，重点优化 AST 生成树与代码结构分析，用 AST 替代或增强纯正则误区诊断，提高 M1-M8 误区识别准确率。
- C：大数据类，由 clt 负责，重点优化推荐系统，基于学习画像、误区历史、练习完成情况和知识点标签实现个性化练习推荐。

## 工程要求

三条方向均通过 Feature Flag 隔离，默认关闭，独立开发，最后逐项开启验证并整合。实现过程中必须同步维护实现文档、实现日志和 Debug 日志。

完整内容请查看同目录 DOCX。
