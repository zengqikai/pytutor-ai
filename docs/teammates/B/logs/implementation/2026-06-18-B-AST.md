## AST 检测规则一览

| 误区 | 方法 | 置信度 | 误报控制 |
|------|------|:---:|------|
| M1 | SyntaxError + 精确正则 `(?<![=!<>:])=(?!=)` | 0.92 | 不误判 `==` `>=` `<=` `!=` `:=` |
| M2 | IndentationError + indent 关键词 | 0.95 | — |
| M3 | Assign->Call->Attribute(attr in INPLACE_METHODS) | 0.92 | 不包含 `pop`; `sorted()`/直接调用不触发 |
| M4 | For(target=Name)->body(Subscript(iter, target)) | 0.90 | `range(len(x))`/`enumerate` 不触发 |
| M5 | range 参数 + stderr/学生问题 >=0.6 分 | <=0.85 | 纯 `range(10)` 只得 0 分，不触发 |
| M6 | FunctionDef 有 print 无 return | 0.88 | 先 print 后 return 不触发 |
| M7 | stderr + BinOp(Add) 单侧常量即可触发 | 0.80 | 无 stderr 时仅双侧常量触发 |
| M8 | While True 无退出 / 条件变量未更新 | 0.92/0.80 | break/return/raise/+=1/=n+1 都不触发 |

## 验证命令与结果

```bash
# 编译检查
python -m compileall backend/app          # ✅ 全部通过

# 单元测试
pytest backend/tests/test_ast_analyzer.py -v  # ✅ 42/42 PASS

# 全关验证（旧正则 baseline）
ENABLE_AST_DIAGNOSIS=false python evaluation/run_v2_eval.py --mode direct

# 单开验证（AST 诊断）

# AST-only 模式（无需数据库/LLM/后端）
python evaluation/run_v2_eval.py --mode ast-only

```
