> 对应完善任务清单 **12**（接入真实模型并完成 AST 证据消融实验）。
> 数据集仍只有 10 条种子（任务 11 的全量 170 条需人工标注，尚未完成），
> 因此本文只回答"链路能不能跑通、量级大概多少"，**不构成对 C2 有效性的结论**。
>
> 2026-10-22 更新：断言抽取器清理了 Markdown 噪声（`rules_v2`），
> 下面以 v2 的两次运行为主结果；v1 数字保留作对照，说明量尺修正前后的差异。

## 1. 实验设置

| 项 | 值 |
|----|----|
| 解释模型 | `deepseek-chat`（`https://api.deepseek.com`） |
| 温度 / max_tokens | 0.3 / 600 |
| 条件 | C1 = 只给代码；C2 = 先注入 AST 结构事实再解释 |
| 数据集 | `dataset_seed.json`，sha256 前 16 位 `8c8e786623216b92`，10 条（5 positive + 5 hard_negative） |
| 断言抽取 / 判定 | `RuleBasedClaimExtractor/rules_v2` + `FaithfulnessVerifier`（确定性规则，与被测模型分离） |
| 抽取器改动 | 丢弃代码块、标题、表格行、分隔线；去掉列表符号/加粗标记；支持英文句末切分；过滤过短引导句 |
| 重复次数 | 2 次独立运行（同参数），用于观察方差 |

运行：

```bash
cd research/faithfulness
python run_experiment.py --model deepseek --out results_real_deepseek_v2_run1.json
```

## 3. 能得出的结论

1. **链路是真实可跑的**：真实模型、真实 prompt、真实 AST 事实、真实判定，0 次失败，
   可断点续跑，结果文件含逐条解释与逐断言 verdict。
2. **C2 没有优于 C1**：v2 两次运行的配对差都是负值（−0.127、−0.090），
   95% CI 都包含 0。不能宣称证据注入提升忠实度；点估计反而略偏向 C1。
   这比 v1 的"两次方向相反"更稳定，但仍然是"没有收益证据"，不是"证明 C1 更好"。
3. **样本量与方差仍是瓶颈**：10 条里只有 5–7 条产生可核验断言，配对样本仅 5 对；
   单条判定翻转就能让分数移动几个百分点。run-to-run 的 C1 差距仍有 0.016–0.15。
4. **hard_negative 是真正暴露幻觉的地方**：N04（干净代码）两次运行、两个条件的忠实度都是 0，
   模型在正确代码上仍断言存在误区。
5. **量尺本身修好了一部分**：Markdown/代码块/表格不再进入断言流；但"意图 vs 结构"的
   启发式分类还没有人工抽查，不能当作已验证的判定质量。

## 4. 已知的量尺缺陷（仍未完成）

- **人工抽查缺失**：任务 10 要求抽取与判定各 ≥30 例人工核对；目前只有单元测试，
  没有人工标注表。规则改动后必须补做，否则 v2 的覆盖率只能算"规则自洽"。
- **分母偏小**：20 份回复里只有 40–42 条可核验断言；C1 在 5 份回复里没有可核验断言，
  所以 `n_scored` 不是 10。
- **意图分类是启发式**：`intent_or_advice` 靠关键词，英文解释只做了句末切分，
  没有系统验证双语抽取一致性。
- **单一模型、单一温度**：没有第二个模型做稳健性检查（C3）。

## 5. 未做 / 不可宣称

- 未做人工标注对照（任务 11、14），因此不能说"C2 提升了教学解释的忠实度"。
- 未做正式功效分析；n=5 配对时 CI 宽度没有参考价值。
- 未接入第二个模型做跨模型稳健性（C3）。
